---
description: 安装独立项目管理插件，在更多菜单中置顶与编辑
---

先定位此命令所属的已安装插件目录，确认 scripts/install.py、runtime/alias.js 与 runtime/loader.cjs 齐全；读取 README.md。执行该目录的 `python3 scripts/install.py doctor`，再执行 `python3 scripts/install.py install`。

本插件有自己的加载器与启停配置，不依赖其他插件。首次需在 ZCode 退出时安装自己的 app.asar 启动入口、更新完整性并建立本机 ad-hoc 签名，再正常启动。若当前有运行中的客户端，安装器只准备自己的文件，返回 prepared/退出码 2；请报告“待长任务结束后安装入口”，不要退出、重启、刷新、重载或终止任何会话。不得借用其他插件的脚本或加载入口来绕过。

已有独立加载器时自己的界面脚本支持热更新。在不影响长任务的前提下确认项目“⋯ 更多”菜单有“置顶 / 编辑 / 移除”，点击编辑后才能修改名称，已置顶项目显示“取消置顶”。不要自动给真实业务项目取昵称或改变置顶状态。没有界面读取能力时明确报告待用户确认，不把磁盘状态当成界面验收。
