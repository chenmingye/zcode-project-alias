# ZCode 项目昵称 0.5.1

独立插件，无其他插件依赖。作者：Jason.chen。

左侧项目的“⋯ 更多”菜单提供“置顶 / 编辑 / 移除”。置顶后项目排到当前列表顶部，菜单变为“取消置顶”；多个置顶项目保留宿主相对顺序。点击“编辑”，在“编辑项目”弹窗修改名称并保存，下方源文件夹卡片只读显示真实目录名和路径。关闭、取消或 Escape 不保存；留空或“恢复原名”可还原。真实目录、仓库与会话归属不变。昵称和置顶状态按路径与远端身份保存在客户端 localStorage，跨窗口同步，重开可恢复。停用时恢复原名与宿主顺序，保留昵称和置顶记录。

需要 macOS、Python 3.9+、Node.js 和 codesign；适配的项目行结构为 ZCode 3.15.3。运行时无需 npm 依赖。

编辑弹窗增加 SVN/Git 候选名称：从本地仓库名、分支、路径层级与上级目录识别前缀。点击 `MES 255/` 填入后可继续输入“管理端”等后缀，也可点击“复制”；不会自动保存或覆盖草稿。可选“格式整理”候选如 `MES 5.5/` 会标明来源，仓库原名保留。不根据技术目录名猜测业务角色。

仓库识别需要对应的 svn/git 命令，只读本地信息，不连接仓库服务器、不拉取、更新或提交，不运行项目脚本。远程工作区暂不在本机识别，命令缺失时回退本地目录候选。识别结果缓存 60 秒，不显示 remote 凭据。

在本插件目录执行：

```bash
python3 scripts/install.py doctor
python3 scripts/install.py install
```

首次安装或更新加载器遇到运行中的 ZCode 时需要重启：若运行中的加载器已是 0.5.1 或更新，由应用自己弹出原生“稍后 / 立即重启”确认；否则安装器弹出带应用图标的系统确认。确认后只发送正常退出事件（不强杀），等待退出、完成安装并自动重新打开；选择稍后或无图形界面时返回 prepared/退出码 2，之后正常退出 ZCode 并重跑 install 即可。脚本场景用 `install --no-prompt` 只准备文件。不要强杀进程、刷新或重载会话。

自己的加载器与配置位于 ~/.zcode/zcode-project-alias/。首次安装在 app.asar 追加自己的启动标记，更新 ASAR/Info.plist 完整性并建立本机 ad-hoc 签名，替换厂商签名；保留 entitlements 与硬化运行时 flags，不关闭完整性校验或修改 fuses。安装前备份应用相关文件，签名失败回滚。不读取或修改其他插件。

已启动独立加载器后，自己的界面脚本支持热更新；加载器本身更新需下次启动。客户端升级可能覆盖入口，需 doctor 后重新安装。

0.5.1 起加载器更新改由应用内原生确认，系统确认框换成带应用图标的样式；0.5.0 修复“编辑项目”弹窗在宿主全局样式重置（`*{margin:0}`）下贴左上角的问题：显式声明弹窗居中，不再依赖 dialog 默认的 auto 边距。

运行中停用：`python3 scripts/install.py uninstall`，约 2 秒内移除自身菜单项并恢复原显示，保留昵称。完整移除入口：应用退出后运行 `python3 scripts/install.py uninstall --remove-hook`。只在市场禁用/卸载命令包不会自动撤销客户端补丁。

当前覆盖左侧“项目”视图。其他标题和搜索结果仍显示原名。不要将磁盘入口已安装等同于真实界面验收通过；检查 doctor 状态并实际打开“更多”菜单确认。
